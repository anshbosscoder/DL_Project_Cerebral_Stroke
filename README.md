# DL_Project_Cerebral_Stroke
This project presents a Cerebral Stroke Prediction Model built using a Sequential Artificial Neural Network (ANN) to assist medical professionals in assessing patient stroke risk. The model uses patient health data for accurate and early prediction of stroke likelihood.

Key features:

Framework: TensorFlow/Keras Sequential ANN

Optimizer: Adam

Loss Function: Binary Cross-Entropy

Evaluation Metric: Accuracy Score

Data Analysis: Performed using Pandas for data cleaning, exploration, and preprocessing


The model learns complex relationships among health factors such as age, hypertension, BMI, and glucose levels to predict the probability of a stroke. By integrating AI in the medical field, this project aims to support doctors in making data-driven decisions and improving patient outcomes.

Future Scope: Integrate with real-time medical databases and enhance model interpretability using SHAP or LIME for clinical usability.
